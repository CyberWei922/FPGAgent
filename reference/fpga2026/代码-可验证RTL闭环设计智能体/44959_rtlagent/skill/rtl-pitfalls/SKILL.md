## Purpose

Use the structured run evidence in `pitfalls.json` before changing a DUT or checker.

## When to use / When not to use

| Use when | Do not use for |
| --- | --- |
| The entry's scope matches a current failure | Rules without qualifying run evidence |
| You can inspect its source artifact | Assuming private archive paths ship in an export |

## Inputs / Outputs

| Option | Meaning |
| --- | --- |
| `--id ID` | Exact entry ID |
| `--category NAME` | Exact category; combine with `--id` as an intersection |
| `--format json` | Default: count and structured entries |
| `--format markdown` | Category tables generated from the same JSON |

Exit 0 means entries were found. Exit 1 means no match. Exit 2 means invalid input or a read failure. Evidence contains artifact path, JSON pointer, artifact SHA-256, run directory, task, commit role and measured numbers.

## Usage

Run from the repository or exported package root.

```sh
SKILLS=rtl-agent/skills
# In an export use SKILLS=skill or SKILLS=competition/skill.
node "$SKILLS/rtl-pitfalls/scripts/rtl-pitfalls.mjs" --format markdown
node "$SKILLS/rtl-pitfalls/scripts/rtl-pitfalls.mjs" --id unsigned-arithmetic-shift
```

## Example

`examples/query.json` is an original CLI query. Run its `args`; compare stdout with `examples/expected.json`. It selects one historical entry without reproducing any task prompt, implementation or testbench.

## Limits

These are observations from our runs, with scoped rules. An audit commit identifies an audit, not necessarily the original runtime version. A report snapshot is labelled separately. Raw artifacts remain in the named archive; only metadata ships here. No reserved task is cited. The five lint entries come from an actual audit and do not claim a separate Vivado reproduction.

The tables below are generated by `--format markdown` and checked by regression tests.

## Source in the agent

This CLI reads `pitfalls.json`. It does not implement a checker. `detect_with` points to the three deterministic CLIs, method preparation or Vivado phases that can investigate the symptom. The agent does not consume this document or data as a prompt; neither is registered in `index.json`.
